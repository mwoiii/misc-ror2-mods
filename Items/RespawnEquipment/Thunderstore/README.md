# Respawn Equipment

Adds the "Umbrous Transceiver", an equipment that lets you swap to any of your unlocked survivors! The equipment UI width, cooldown, and granted immunity window are all configurable, with support for Risk of Options!

Bigs thanks to Knightfall for commissioning this mod!
